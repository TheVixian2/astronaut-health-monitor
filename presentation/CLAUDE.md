# presentation — CLAUDE.md

**Owner: dbm711.** Shared folder — **everyone writes here**, this is the one
exception to "edit only your own lane." dbm711 owns the pitch and works
*only* in this folder; everyone else drops ideas in as they come up.

**Work on `main`, not a lane branch** (coordination rule 3b) — `presentation/`
is a shared path, so edits go straight to `main`: pull, small commit, push.

## What goes here

Anything that is about *how we show the project*, not about how it works:

- demo choreography and timings
- framing, analogies and one-liners that land with judges
- facts and figures worth quoting, **with a source link**
- screenshots or stills worth keeping for slides
- things to deliberately *not* say or show

## The rule

**When an idea comes up that belongs in the pitch rather than the code, write it
into `ideas.md` immediately.** Don't keep it in your head and don't leave it
buried in a Claude Code session — those get cleared. One bullet is enough; it
can be tidied later.

This applies to Claude Code sessions too: if a conversation produces a framing,
a number, or a demo beat worth using on stage, append it to `ideas.md` in the
same turn.

## Files

- `demo-script.md` — the live run-through, in order, with timings.
- `ideas.md` — the dumping ground. Unsorted is fine. Dated bullets.
